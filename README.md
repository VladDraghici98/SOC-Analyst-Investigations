About This Repository

Welcome! 

This repository documents my hands-on journey into cybersecurity, with a focus on Security Operations Center (SOC) analysis, incident investigation, and incident response.

I use practical labs and investigation scenarios to improve my ability to analyze security alerts, investigate suspicious activity, identify indicators of compromise (IOCs), and understand how security incidents are detected and handled.

My goal is to build practical skills and develop a structured approach to investigating security incidents in real-world environments.

Areas of Focus

Security alert triage and investigation

Log analysis and suspicious activity detection

Phishing email and malicious attachment analysis

Network traffic analysis using Wireshark

Incident response fundamentals

Threat intelligence and IOC investigation

MITRE ATT&CK framework

Windows and Linux security fundamentals

Network security and troubleshooting

Tools & Platforms

LetsDefend — SOC analyst investigation labs

Hybrid Analysis — malware analysis and sandbox reports

Cisco Packet Tracer — networking and security labs
